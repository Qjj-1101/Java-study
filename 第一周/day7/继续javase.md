# 正则表达式（Regular Expression）全知识点梳理（Marktext兼容版）

正则表达式（简称Regex/RegExp）是一种用于匹配、查找、替换字符串的强大工具，通过预定义的语法规则描述字符模式，广泛应用于文本处理、数据验证、爬虫、日志分析等场景。以下是系统且完整的正则表达式知识点总结。

## 一、基础概念

### 1. 核心定义

正则表达式是由**普通字符**（如字母、数字、符号）和**元字符**（具有特殊含义的字符）组成的字符序列，用于匹配字符串中符合特定模式的子串。

### 2. 核心功能

- 匹配（Match）：验证字符串是否符合指定模式（如手机号、邮箱格式）；

- 查找（Search）：从字符串中提取符合模式的子串；

- 替换（Replace）：将匹配到的子串替换为指定内容；

- 分割（Split）：按匹配的模式分割字符串。

### 3. 适用场景

- 数据验证（手机号、邮箱、身份证号）；

- 文本清洗（去除特殊字符、提取关键信息）；

- 编程开发（字符串处理、日志解析）；

- 编辑器/工具（VS Code、Notepad++、grep命令）。

## 二、正则表达式语法

### 1. 普通字符

无特殊含义的字符，匹配自身，包括：

- 字母：`a-z`、`A-Z`；

- 数字：`0-9`；

- 符号：`_`、`@`、`#`、`&`等（未被定义为元字符的符号）。

示例：`hello` 匹配字符串中的 `hello` 子串。

### 2. 元字符（核心）

元字符是正则的核心，需转义（加`\`）才能匹配自身，常用元字符如下：

| 元字符     | 含义                                        | 示例                                          |
| ------- | ----------------------------------------- | ------------------------------------------- |
| `.`     | 匹配除换行符（`\n`）外的任意单个字符                      | `a.c` 匹配 `abc`、`a1c`、`a@c`，不匹配 `ac`、`a\nc`  |
| `^`     | 匹配字符串的**开头**（多行模式下匹配每行开头）                 | `^hello` 匹配 `hello world`，不匹配 `world hello` |
| `$`     | 匹配字符串的**结尾**（多行模式下匹配每行结尾）                 | `world$` 匹配 `hello world`，不匹配 `world hello` |
| `*`     | 匹配前面的字符/子表达式**0次或多次**（贪婪匹配）               | `a*` 匹配 `''`、`a`、`aa`、`aaa`                 |
| `+`     | 匹配前面的字符/子表达式**1次或多次**（贪婪匹配）               | `a+` 匹配 `a`、`aa`，不匹配 `''`                   |
| `?`     | 匹配前面的字符/子表达式**0次或1次**；或取消贪婪匹配（加在`*`/`+`后） | `a?` 匹配 `''`、`a`；`a+?` 匹配最短的`a`序列           |
| `{n}`   | 匹配前面的字符/子表达式**恰好n次**                      | `a{3}` 匹配 `aaa`，不匹配 `aa`、`aaaa`             |
| `{n,}`  | 匹配前面的字符/子表达式**至少n次**                      | `a{2,}` 匹配 `aa`、`aaa`，不匹配 `a`               |
| `{n,m}` | 匹配前面的字符/子表达式**n到m次**（包含n和m）               | `a{2,4}` 匹配 `aa`、`aaa`、`aaaa`               |
| `[]`    | 字符集，匹配括号内的任意单个字符（支持范围）                    | `[abc]` 匹配 `a`/`b`/`c`；`[0-9a-z]` 匹配数字或小写字母 |
| `[^]`   | 否定字符集，匹配不在括号内的任意单个字符                      | `[^0-9]` 匹配非数字字符                            |
| `\\     | `                                         | 或，匹配多个表达式中的任意一个                             |
| `()`    | 分组，将多个字符视为一个整体；可捕获匹配结果                    | `(ab)+` 匹配 `ab`、`abab`                      |
| `\`     | 转义符，将元字符转为普通字符                            | `\.` 匹配 `.`；`\*` 匹配 `*`                     |
| `\b`    | 单词边界（匹配单词开头/结尾，非字母数字下划线的位置）               | `\bhello\b` 匹配 `hello`，不匹配 `helloworld`     |
| `\B`    | 非单词边界                                     | `\Bhello\B` 匹配 `helloworld` 中的 `hello`      |
| `\d`    | 匹配数字（等价于 `[0-9]`）                         | `\d{3}` 匹配 `123`                            |
| `\D`    | 匹配非数字（等价于 `[^0-9]`）                       | `\D` 匹配 `a`、`@`                             |
| `\s`    | 匹配空白字符（空格、制表符`\t`、换行符`\n`、回车符`\r`等）       | `\s+` 匹配多个空格                                |
| `\S`    | 匹配非空白字符                                   | `\S` 匹配 `a`、`1`                             |
| `\w`    | 匹配字母、数字、下划线（等价于 `[a-zA-Z0-9_]`）           | `\w+` 匹配 `user123`                          |
| `\W`    | 匹配非字母、数字、下划线（等价于 `[^a-zA-Z0-9_]`）         | `\W` 匹配 `@`、`#`                             |

### 3. 贪婪匹配与非贪婪匹配

- **贪婪匹配**：默认行为，尽可能匹配更多字符（`*`、`+`、`{n,}`）；

- **非贪婪匹配**：在量词后加`?`，尽可能匹配更少字符。

示例：

- 字符串 `aaaaa`，`a+`（贪婪）匹配整个 `aaaaa`；`a+?`（非贪婪）匹配第一个 `a`；

- 字符串 `<div>test</div><div>demo</div>`，`<.*>`（贪婪）匹配整个字符串；`<.*?>`（非贪婪）匹配 `<div>` 和 `</div>` 等单个标签。

### 4. 分组与捕获

#### （1）普通分组 `()`

将多个字符分组，量词作用于整个分组：

示例：`(ab){2}` 匹配 `abab`。

#### （2）捕获分组

分组默认会捕获匹配结果，可通过`\数字`（正则内）或`$数字`（替换时）引用：

- 示例1（正则内引用）：`(\w+)\s\1` 匹配 `hello hello`（`\1` 引用第一个分组的结果）；

- 示例2（替换时引用）：将 `name=张三` 替换为 `张三`，可用正则 `name=(.*)`，替换为 `$1`。

#### （3）非捕获分组 `(?:)`

仅分组，不捕获匹配结果，节省性能：

示例：`(?:ab)+` 匹配 `abab`，但无法通过`\1`引用。

#### （4）命名分组 `(?<name>...)`

给分组命名，便于引用（部分语言支持，如Python、Java）：

示例：`(?<username>\w+)@`，匹配 `user123@` 后，可通过名称`username`获取分组结果。

### 5. 零宽断言（预查）

匹配位置，不消耗字符，仅判断前后是否符合条件，分为四种：

| 断言类型   | 语法         | 含义              | 示例                             |
| ------ | ---------- | --------------- | ------------------------------ |
| 正向先行断言 | `(?=...)`  | 匹配后面符合`...`的位置  | `\d+(?=元)` 匹配 `100元` 中的 `100`  |
| 负向先行断言 | `(?!...)`  | 匹配后面不符合`...`的位置 | `\d+(?!元)` 匹配 `100`（后面无`元`）    |
| 正向后行断言 | `(?<=...)` | 匹配前面符合`...`的位置  | `(?<=￥)\d+` 匹配 `￥100` 中的 `100` |
| 负向后行断言 | `(?<!...)` | 匹配前面不符合`...`的位置 | `(?<!￥)\d+` 匹配 `100`（前面无`￥`）   |

示例：验证密码强度（至少8位，包含大小写字母和数字）：

`^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$`

## 三、正则表达式修饰符（标志）

修饰符用于调整正则的匹配规则，不同语言/工具的修饰符语法略有差异（如JavaScript用`/pattern/flags`，Python用`re.compile(pattern, flags)`），常用修饰符：

| 修饰符 | 别名（Python）      | 含义                        |
| --- | --------------- | ------------------------- |
| `i` | `re.IGNORECASE` | 忽略大小写                     |
| `m` | `re.MULTILINE`  | 多行模式（`^`匹配每行开头，`$`匹配每行结尾） |
| `s` | `re.DOTALL`     | 单行模式（`.`匹配包括换行符在内的所有字符）   |
| `g` | -（JavaScript专属） | 全局匹配（匹配所有符合条件的子串，而非仅第一个）  |
| `u` | `re.UNICODE`    | 匹配Unicode字符（Python3默认支持）  |
| `x` | `re.VERBOSE`    | 忽略正则中的空格和注释，便于编写易读的正则     |

示例（Python）：

```python
import re# 忽略大小写 + 多行模式pattern = re.compile(r'^hello', re.IGNORECASE | re.MULTILINE)
```

## 四、常见正则表达式示例

### 1. 基础验证

- 手机号（中国大陆）：`^1[3-9]\d{9}$`

- 邮箱：`^[a-zA-Z0-9_-]+@[a-zA-Z0-9_-]+(\.[a-zA-Z0-9_-]+)+$`

- 身份证号（18位）：`^[1-9]\d{5}(19|20)\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])\d{3}[\dXx]$`

- 邮政编码（中国大陆）：`^[1-9]\d{5}$`

- URL：`^https?://[a-zA-Z0-9.-]+\.[a-zA-Z]{2,6}(/\S*)?$`

- 密码（8-16位，字母+数字）：`^(?=.*[a-zA-Z])(?=.*\d)[a-zA-Z\d]{8,16}$`

### 2. 文本提取

- 提取所有数字：`\d+`

- 提取HTML标签内的文本：`<([a-zA-Z0-9]+)>(.*?)</\1>`

- 提取字符串中的邮箱：`[a-zA-Z0-9_-]+@[a-zA-Z0-9_-]+(\.[a-zA-Z0-9_-]+)+`

### 3. 文本替换

- 去除所有空格：正则 `\s+`，替换为 `''`

- 将手机号中间4位替换为`*`：正则 `(\d{3})\d{4}(\d{4})`，替换为 `$1****$2`

## 五、正则表达式的实现与工具

### 1. 编程语言中的支持

几乎所有编程语言都内置正则表达式库：

- Python：`re` 模块（`re.match`、`re.search`、`re.findall`、`re.sub`）；

- JavaScript：`RegExp` 对象（`test`、`exec`）、字符串方法（`match`、`replace`、`split`）；

- Java：`java.util.regex` 包（`Pattern`、`Matcher`）；

- PHP：`preg_*` 系列函数（`preg_match`、`preg_replace`）；

- Go：`regexp` 包。

### 2. 常用工具

- 在线测试：Regex101（https://regex101.com/）、菜鸟工具正则测试（https://c.runoob.com/front-end/854/）；

- 编辑器：VS Code、Sublime Text、Notepad++（内置正则查找替换）；

- 命令行：`grep`、`sed`、`awk`（Linux/Unix）。

## 六、注意事项与最佳实践

### 1. 转义问题

不同语言的转义规则不同（如Python中`\`需写成`\\`，或用原始字符串`r''`），避免转义错误。

### 2. 性能优化

- 避免过度使用贪婪匹配，优先使用非贪婪或精准匹配；

- 复杂正则拆分为多个简单正则，减少回溯；

- 非捕获分组`(?:)`替代普通分组，减少内存消耗；

- 避免嵌套量词（如`(a+)+`），易导致正则回溯爆炸。

### 3. 可读性

- 长正则添加注释（通过`x`修饰符）；

- 分组命名提升可维护性；

- 复杂场景拆分正则，而非写一个超大正则。

### 4. 边界测试

- 测试空字符串、极端长度字符串、特殊字符；

- 验证正则是否匹配预期外的字符串（如手机号正则是否匹配10位数字）。

## 七、常见误区

1. 过度依赖正则：复杂场景（如HTML解析）优先使用专用库（如BeautifulSoup），而非正则；

2. 忽略换行符：默认`.`不匹配`\n`，需开启`s`修饰符；

3. 单词边界理解错误：`\b`匹配的是“非单词字符”与“单词字符”的边界，而非空格；

4. 贪婪匹配导致结果超出预期：未加`?`的量词会尽可能匹配更多字符。

以上是正则表达式的完整知识点，掌握核心语法和最佳实践后，可高效解决各类文本处理问题。

正则表达式可以用来搜索、编辑或处理文本。

正则表达式并不仅限于某一种语言，但是在每种语言中有细微的差别。

Java 提供了 java.util.regex 包，它包含了 Pattern 和 Matcher 类，用于处理正则表达式的匹配操作。
