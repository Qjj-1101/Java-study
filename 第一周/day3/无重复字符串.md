# 3. 无重复字符的最长子串（LeetCode 003）

## 🧩 题目简述

给定一个字符串 `s`，找出**不含有重复字符**的**最长连续子串**的长度。

**示例**  
输入: `"abcabcbb"`  
输出: `3`  
解释: 最长无重复子串是 `"abc"`，长度为 3。

---

## 💡 核心思想：滑动窗口（Sliding Window）

维护一个**动态区间** `[left, right]`，保证区间里**绝无重复字符**；  
右指针 `right` 一直往右扫，发现重复立即把左指针 `left` 跳到“重复位置 + 1”，把旧字符踢出去；  
扫描过程中随时更新历史最大长度 `max`。

## 🛠 关键数据结构

| 名称   | 作用               | 本次实现                 |
| ---- | ---------------- | -------------------- |
| 滑动窗口 | 保存当前无重复子串        | 双指针 `left` / `right` |
| 哈希表  | 记录字符**最近一次**出现下标 | 数组 `int[256] last`   |

## 📝 代码（Java）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[256];          // 1. 小本本：字符→最近一次下标
        Arrays.fill(last, -1);              //    初始化为 -1（未出现）

        int left = 0;                       // 2. 窗口左边界
        int max  = 0;                       // 3. 历史最大长度
    
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);       // 4. 当前要入窗的字符
    
            // 5. 重复且仍在窗口内 → 移动左边界
            if (last[c] >= left) {
                left = last[c] + 1;
            }
            last[c] = right;                // 6. 更新“最近一次”下标
            max = Math.max(max, right - left + 1); // 7. 刷新历史最佳
        }
        return max;
    }

}



 关键：类似一个滑动的窗口，遇到重复的找该重复字符的下一个字符做left
