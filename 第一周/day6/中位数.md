# 寻找两个有序数组的中位数 笔记

## 一、题目背景

给定两个**有序整数数组** `nums1` 和 `nums2`，要求找出并返回这两个数组的中位数，时间复杂度需优化至 O(log(m+n))（m、n 分别为两个数组长度）。

### 中位数定义

- 合并后数组长度为**奇数**：中位数是中间位置的数；
- 合并后数组长度为**偶数**：中位数是中间两个数的平均值。

## 二、核心思路

采用**二分查找**分割两个数组，满足「左半部分所有数 ≤ 右半部分所有数」，直接通过分割点计算中位数，避免合并数组（合并数组时间复杂度为 O(m+n)，不满足要求）。

### 核心分割规则

1. 左半部分总长度 = `(m + n + 1) / 2`（+1 保证奇数长度时左半部分多一个数，可直接取左半最大值为中位数）；
2. 分割后需满足：
   - `nums1` 左半最大值 ≤ `nums2` 右半最小值；
   - `nums2` 左半最大值 ≤ `nums1` 右半最小值；
3. 始终让较短数组作为二分查找的核心，减少查找次数。

## 三、完整代码

运行

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 获取数组长度
        int m = nums1.length;
        int n = nums2.length;

        // 处理其中一个数组为空的边界情况
        if (m == 0) {
            return (n & 1) == 1 ? nums2[n / 2] : (nums2[n / 2 - 1] + nums2[n / 2]) / 2.0;
        }
        if (n == 0) {
            return (m & 1) == 1 ? nums1[m / 2] : (nums1[m / 2 - 1] + nums1[m / 2]) / 2.0;
        }

        // 保证nums2是较短数组，减少二分次数
        if (nums2.length > nums1.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        // 左半部分总长度（奇数时左半多一个）
        int halfLen = (m + n + 1) / 2;

        // 初始化nums1的二分边界
        int left = Math.max(0, halfLen - n);
        int right = Math.min(m, halfLen);

        // 二分查找分割点
        while (left <= right) {
            int i = (right + left) / 2; // nums1分割点（左半有i个元素）
            int j = halfLen - i;         // nums2分割点（左半有j个元素）

            // 调整分割点：nums1右半最小值 < nums2左半最大值 → 增大i
            if (i < m && j > 0 && nums1[i] < nums2[j - 1]) {
                left = i + 1;
            }
            // 调整分割点：nums1左半最大值 > nums2右半最小值 → 减小i
            else if (i > 0 && j < n && nums1[i - 1] > nums2[j]) {
                right = i - 1;
            }
            // 找到合法分割点，计算中位数
            else {
                // 计算左半部分最大值
                int maxLeft;
                if (i == 0) {
                    maxLeft = nums2[j - 1];
                } else if (j == 0) {
                    maxLeft = nums1[i - 1];
                } else {
                    maxLeft = Math.max(nums1[i - 1], nums2[j - 1]);
                }

                // 总长度为奇数，直接返回左半最大值
                if ((m + n) % 2 == 1) {
                    return maxLeft;
                }

                // 计算右半部分最小值
                int minRight;
                if (i == m) {
                    minRight = nums2[j];
                } else if (j == n) {
                    minRight = nums1[i];
                } else {
                    minRight = Math.min(nums1[i], nums2[j]);
                }

                // 总长度为偶数，返回左右平均值
                return (maxLeft + minRight) / 2.0;
            }
        }

        // 理论上不会执行到此处
        return 0.0;
    }
}
```

## 四、关键细节解析

| 代码片段                                                                                | 功能说明                             |
| ----------------------------------------------------------------------------------- | -------------------------------- |
| `if (nums2.length > nums1.length) { return findMedianSortedArrays(nums2, nums1); }` | 保证二分查找在较短数组的 “镜像” 上进行，减少查找次数     |
| `int halfLen = (m + n + 1) / 2`                                                     | 定义左半部分总长度，奇数时左半多一个元素，简化中位数计算     |
| `i = (right + left) / 2; j = halfLen - i`                                           | 分割点满足 `i + j = halfLen`，保证左右长度平衡 |
| `i == 0 / j == 0 / i == m / j == n`                                                 | 处理分割点越界情况（某个数组左 / 右半部分为空）        |
| `(n & 1) == 1`                                                                      | 位运算判断奇偶性，比 `n % 2 == 1` 效率更高     |

## 五、时间 / 空间复杂度

- **时间复杂度**：O(log(min(m,n)))，二分查找的范围是较短数组的长度；
- **空间复杂度**：O(1)，仅使用常量级额外空间。

## 六、常见易错点

1. 分割点越界未处理（如 `i=0` 时直接取 `nums1[i-1]` 导致数组越界）；
2. 二分边界初始化错误（未考虑 `halfLen - n`，导致分割点超出数组范围）；
3. 偶数长度计算时未用浮点数（如 `(maxLeft + minRight) / 2` 导致整数除法丢失精度）；
4. 奇偶判断错误（未处理 `(m + n) % 2 == 1` 的情况）。

## 七、示例验证

### 示例 1：奇数长度

输入：`nums1 = [1,3], nums2 = [2]`

- m=2，n=1 → `halfLen = (2+1+1)/2 = 2`
- 二分找到 `i=1, j=1` → 左半最大值 `max(1,2)=2` → 直接返回 2。

### 示例 2：偶数长度

输入：`nums1 = [1,2], nums2 = [3,4]`

- m=2，n=2 → `halfLen = (2+2+1)/2 = 2`
- 二分找到 `i=1, j=1` → 左半最大值 `max(1,3)=3`，右半最小值 `min(2,4)=2` → 中位数 `(3+2)/2=2.5`。

自我总结：

1.通过两个有序数组的长度确定halfLen，确定左边的长度 (左边长度要大)：m+n+1/2，保证如果是奇数，直接取到左边的最大值即可，如果是偶数那么就取左边最大值和右边最小值之和的一半。

2.当确定左边的放个数后，然后从短的里面开始选（短的约束条件），短的选出来的放在左边，长数组中选出来的放在右边，设这个短的从i开始，长的从j开始，当短的选i个，长的选halflen-i =j个 ，并且这个i最终选出来的是唯一的（左边选的从少变多，而右边选的从多变少，里面的数一个递增，一个递减），最终选出来的halflen中，最大值即中位数。

把两个数组，分成两半，然后分别去比最大值和最小值

根据确定需要的长度去切割，切割之和就会分成四部分，然后num1最小去比较num2的最大，以此类推
