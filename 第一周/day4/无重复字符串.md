# 3. 无重复字符的最长子串

LeetCode 原题地址：https://leetcode.cn/problems/longest-substring-without-repeating-characters/

---

## 一、题目描述

给定一个字符串 `s`，请你找出**不含有重复字符**的**最长子串**的长度。  

**提示：**  

- `0 ≤ s.length ≤ 5 × 10⁴`  
- `s` 由英文字母、数字、符号和空格组成  

---

## 二、思路概览

**滑动窗口（Sliding Window）**  
维护一个**动态窗口** `[left, right]`，保证窗口内字符**绝无重复**：  

1. 右指针 `right` 不断右移，扩张窗口。  
2. 若新字符 `c` 在窗口**已出现过**，则把左指针 `left` 直接跳到“上次出现位置 + 1”，**一次性收缩**。  
3. 每一步计算窗口长度 `right - left + 1`，更新全局最大值 `max`。  

**核心观察：**  

- 每个字符**最多被访问两次**（被 `right` 扫一次，被 `left` 跳一次）。  
- 时间复杂度 **O(n)**，空间 **O(Σ)**（Σ 为字符集大小）。  

---

## 三、完整代码（Java）

```java
import java.util.Arrays;

public class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 1. 记录字符最近一次出现下标，初始化为 -1 表示“未出现”
        int[] last = new int[128];          // 纯 ASCII 足够；128 代替 256 省内存
        Arrays.fill(last, -1);

        int left = 0;   // 窗口左边界（包含）
        int max  = 0;   // 历史最大长度

        // 2. 右指针不断扩张
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);

            // 3. 如果 c 在当前窗口内重复，则收缩左边界
            if (last[c] >= left) {
                left = last[c] + 1;
            }

            // 4. 更新 c 的最新位置
            last[c] = right;

            // 5. 计算当前窗口长度并更新答案
            max = Math.max(max, right - left + 1);
        }
        return max;
    }

}



运用滑动窗口的思想去做，找字符串中不重复字符的最大值
```
