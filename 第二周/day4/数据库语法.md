# 📚 Java 数据库学习笔记 (JDBC & 基础 SQL)

## 一、数据库表结构 (`employee` 表)

这是我们所有实践操作的基础表结构定义：

| **列名 (Name)** | **数据类型 (Data Type)** | **约束/特点**                 | **Java 中对应类型**          | **备注**       |
| ------------- | -------------------- | ------------------------- | ----------------------- | ------------ |
| `employee_id` | `INT`                | 主键 (PK), `AUTO_INCREMENT` | `int`                   | 自动生成，插入时无需指定 |
| `first_name`  | `VARCHAR(50)`        | `NOT NULL`                | `String`                | 员工名字         |
| `last_name`   | `VARCHAR(50)`        | `NOT NULL`                | `String`                | 员工姓氏         |
| `department`  | `VARCHAR(50)`        | `NULL`                    | `String`                | 所在部门         |
| `salary`      | `DECIMAL(10, 2)`     | `NULL`                    | `double` / `BigDecimal` | 薪水，两位小数      |
| `hire_date`   | `DATE`               | `NULL`                    | `java.sql.Date`         | 入职日期         |

## 二、核心 SQL 语法 (DML & DDL 基础)

### 1. DDL (数据定义语言) 基础

- **创建表 (CREATE TABLE):** 确定数据结构和约束。

- CREATE TABLE employee (
  
      employee_id INT PRIMARY KEY AUTO_INCREMENT,
      first_name VARCHAR(50) NOT NULL,
      last_name VARCHAR(50) NOT NULL,
      -- ... 其他列定义
  
  );
  
  2. DML (数据操作语言) - 增、删、改
     
     | **操作** | **关键字**       | **SQL 格式**                                                       | **重点/警告**                        |
     | ------ | ------------- | ---------------------------------------------------------------- | -------------------------------- |
     | **增**  | `INSERT INTO` | `INSERT INTO employee (col1, col2) VALUES ('value1', 'value2');` | **类型匹配**：值必须与列的数据类型兼容。           |
     | **改**  | `UPDATE`      | `UPDATE employee SET salary = 65000 WHERE employee_id = 1;`      | **⚠️ 必须使用 `WHERE`**，否则会更新表中所有记录。 |
     | **删**  | `DELETE FROM` | `DELETE FROM employee WHERE department = '行政部';`                 | **⚠️ 必须使用 `WHERE`**，否则会删除表中所有记录。 |

### DML - 查 (`SELECT`) 核心语法

这是工作中最重要的部分。

| **语句**                                     | **作用** | **最佳实践**                 |
| ------------------------------------------ | ------ | ------------------------ |
| `SELECT * FROM employee;`                  | 查询所有列。 | **仅用于练习或临时查询。**          |
| `SELECT first_name, salary FROM employee;` | 查询指定列。 | **工作中强烈推荐**，能提高性能和代码健壮性。 |

B. 数据筛选与组合 (`WHERE` 子句)

| **场景**   | **关键字**                   | **示例**                                 | **解释**        |
| -------- | ------------------------- | -------------------------------------- | ------------- |
| **精确匹配** | `=`                       | `WHERE department = '研发部'`             | 查找特定值。        |
| **范围查询** | `BETWEEN`                 | `WHERE salary BETWEEN 50000 AND 90000` | 查找包含边界值在内的范围。 |
| **集合查询** | `IN`                      | `WHERE department IN ('市场部', '销售部')`   | 查找属于列表中的任意值。  |
| **模糊查询** | `LIKE`                    | `WHERE last_name LIKE '张%'`            | `%` 匹配任意多个字符。 |
| **空值判断** | `IS NULL` / `IS NOT NULL` | `WHERE hire_date IS NOT NULL`          | 判断字段是否为空值。    |
| **逻辑组合** | `AND` / `OR`              | `WHERE dept='研发部' AND salary > 80000`  | 组合多个条件。       |

C. 排序与限制 (`ORDER BY` & `LIMIT`)

| **关键字** | **作用**                | **示例**                                | **解释**                                 |
| ------- | --------------------- | ------------------------------------- | -------------------------------------- |
| **排序**  | `ORDER BY`            | `ORDER BY salary DESC, last_name ASC` | **`DESC`** 降序，**`ASC`** 升序（默认）。支持多列排序。 |
| **限制**  | `LIMIT`               | `ORDER BY salary DESC LIMIT 3`        | 用于获取 Top N 记录（前 3 个）。                  |
| **分页**  | `LIMIT offset, count` | `LIMIT 5, 5`                          | 跳过前 5 条记录，取接下来的 5 条（第二页）。              |

# 📝 SQL `LIMIT` 子句总结

`LIMIT` 子句用于**限制查询结果集返回的行数**，是 SQL 中实现数据排行榜和分页功能的核心工具。

## 1. 基本语法

`LIMIT` 子句必须放在 `SELECT` 语句的末尾，通常紧跟在 `ORDER BY` 之后。

SQL

```
SELECT columns
FROM table_name
[WHERE conditions]
[ORDER BY column_name ASC|DESC]
LIMIT [offset,] count;
```

---

## 2. 两种核心用法

### 用法 A: 限制返回数量 (获取 TOP N)

只使用一个参数 `count`，表示从结果集的第一条记录开始，最多返回多少条。

| **目的**       | **语法**        | **示例 (获取薪水最高的 3 名员工)**                                 |
| ------------ | ------------- | ------------------------------------------------------ |
| **返回 N 条记录** | `LIMIT count` | `SELECT * FROM employee ORDER BY salary DESC LIMIT 3;` |

- **重点：** 要获取“最高”或“最低”的记录，**必须**先使用 `ORDER BY` 对数据进行排序。

### 用法 B: 数据分页 (跳过 + 限制)

使用两个参数 `offset` 和 `count`，实现数据分页。

| **参数**       | **含义**                     | **示例**                     |
| ------------ | -------------------------- | -------------------------- |
| **`offset`** | 要**跳过**的记录数（起始位置为 0）。      | `LIMIT 5, 10`：跳过前 5 条。     |
| **`count`**  | 从跳过位置开始，要**返回**的记录数（每页大小）。 | `LIMIT 5, 10`：返回接下来的 10 条。 |

---

## 3. 分页查询公式 (工作常用)

在程序中实现分页时，`offset` 是根据当前页码计算出来的。

假设：

- **$P$** = 每页显示的记录数 (`count`)

- **$N$** = 当前要查询的页码

| **参数**              | **计算公式**             |
| ------------------- | -------------------- |
| **`offset` (起始位置)** | $$(N - 1) \times P$$ |
| **`count` (每页大小)**  | $$P$$                |

| **示例**    | **页码 (N)** | **每页 (P)** | **OFFSET 计算**              | **对应的 LIMIT 语句** |
| --------- | ---------- | ---------- | -------------------------- | ---------------- |
| **第 1 页** | 1          | 5          | $$(1 - 1) \times 5 = 0$$   | `LIMIT 0, 5`     |
| **第 3 页** | 3          | 10         | $$(3 - 1) \times 10 = 20$$ | `LIMIT 20, 10`   |

### 关键原则

- **稳定排序：** 在使用 `LIMIT` 进行分页时，**必须**配合 `ORDER BY` 子句，以确保数据返回的顺序是固定的，否则分页会混乱。
