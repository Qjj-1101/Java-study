# Week 3-4 学习任务清单

## 一、Java 集合 & 异常

1. 集合核心实现类
- List 接口：重点掌握 ArrayList 实现类的使用、特性及底层原理

- Set 接口：了解常用实现类（如 HashSet）的特性

- Map 接口：重点掌握 HashMap 实现类的使用、存储结构及常用方法
2. 集合遍历方式
- for-each 循环遍历集合

- Iterator 迭代器遍历（含迭代器的核心方法、快速失败机制）
3. 异常处理
- 异常捕获：try-catch-finally 语法及执行流程

- 异常抛出：throws 关键字的使用场景

- 自定义异常：自定义异常类的编写及使用

## 二、面向对象进阶

1. 接口（interface）
- 接口的定义、特性（如多继承、默认方法、静态方法）

- 接口的实现（implements 关键字）及使用场景
2. 抽象类
- 抽象类的定义、特性（含抽象方法、非抽象方法）

- 抽象类与接口的区别
3. 设计思路实践
- 「一个接口多种实现」的设计模式落地（如定义统一接口，编写不同实现类）

## 三、MySQL 基础

1. 环境搭建
- MySQL 安装与配置（含服务启动、用户权限设置）
2. 基础 SQL 语法
- 建表：CREATE TABLE 语句

- 增删改查：INSERT、DELETE、UPDATE、SELECT 语句

- 条件与排序：WHERE 条件查询、ORDER BY 排序、LIMIT 分页

## 四、Java 与 MySQL 连接（JDBC）

1. 核心目标
- 掌握 JDBC 核心 API （DriverManager、Connection、Statement/PreparedStatement、ResultSet）
2. 实践案例
- 编写 Java 代码实现数据库数据插入操作

- 编写 Java 代码实现数据库数据查询操作
